# ☕ 달빛 커피 배달단 — 별빛타운 커피 배달 경영 게임

Week3 프롬프트 구조화 실습([원본 과제 저장소](https://github.com/Sjsj-prompt/coffee-delivery-game-week3))의 커피 배달 게임을, 다섯 칸 구조 프롬프트 한 번으로 **새 컨셉의 경영 게임**으로 다시 만든 결과물입니다.

- 게임: `index.html` 하나로 실행 (설치·서버·API 키 불필요, 외부 라이브러리 없음)
- 실습 기록지: [WORKSHEET.md](WORKSHEET.md) — 사용한 프롬프트, 확인 결과, 후속 수정, 회고
- 사용 도구: Claude Code · Claude Opus 5.5

## 실행 방법

1. 위쪽 초록색 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. **index.html**을 Chrome, Edge, Safari 등 브라우저로 엽니다.
3. **시작 / 계속**을 누르면 세계관 프롤로그가 나오고, 이어서 게임이 시작됩니다.

## 이야기

회사·대학·주거지가 모인 작은 동네 **별빛타운**. 할머니가 40년 지켜온 카페 '달빛 커피'를 물려받았지만 타운 카페 랭킹은 꼴찌입니다.
손님이 오지 않으면 내가 간다! 포스기로 주문을 받고, 직접 만들고, 두 발로 배달해서 **4주 뒤 카페 랭킹 1위**를 노리세요.

## 조작

| 하고 싶은 일 | 조작 |
|---|---|
| 시작·계속 / 잠깐 멈추기 / 처음으로 | 화면 아래 버튼 |
| 이동 | 방향키, W/A/S/D, 화면 아래 화살표 |
| 상호작용 (제조·배달·벤치·판촉·인사) | E 또는 Space, `상호작용 (E)` 버튼 |
| 포스기 열기 | P 또는 Tab, 오른쪽 위 주문 목록 클릭 |
| 메뉴 제조 | Space를 누르고 있다가 초록 구간에서 떼기 |
| 판촉 미니게임 | 타이밍에 맞춰 Space → Space 연타 |
| 창 닫기 / 소리 끄기 | Esc / M 또는 `소리 끄기` 버튼 |

## 게임 규칙

- **배달 흐름**: 주문 알림 → 포스기에서 승인(90분 안에 안 하면 취소) → 카운터에서 제조 → 주문자 건물까지 걸어가 배달. 한 번에 4잔까지 들 수 있고, 승인 후 150분이 지나면 지각입니다.
- **메뉴 12종 × 핫/아이스**: 아메리카노, 카페라떼, 카푸치노, 카라멜마끼야또, 바닐라라떼, 초코라떼, 말차라떼, 밀크티, 녹차, 페퍼민트티, 홍차, 루이보스티. 핫은 스팀 소리, 아이스는 얼음 굴리는 소리.
- **에너지 100**: 이동·판촉 시 감소. 20 이하면 피곤 상태(속도 60%). 벤치에서 쉬기 +5(같은 벤치는 1시간 뒤 다시), 영업 종료 후 집에서 자면 100. 자정까지 집에 못 가면 쓰러져 다음 날 70으로 시작.
- **정기 배달 판촉**: 배달 후 또는 `! 판촉 찬스` 주민에게 무작위 발생. 성공하면 매일 오픈 때 자동 주문(보상 ×1.5) + 30G.
- **하루·주·달**: 하루마다 데일리 퀘스트 3개, 영업시간은 포스기에서 설정(오픈 7–12시, 마감 15–23시). 7일마다 주간 리포트, 28일째 별빛타운 카페 랭킹 발표.
- **화면 구성**: 왼쪽 위 에너지·시간, 오른쪽 위 미니맵·주문 3건(누르면 포스기), 왼쪽 아래 15초마다 익명 리뷰, 오른쪽 아래 인기 지수·골드·랭킹.
